# Single ESP32 — Dedicated On-Device Signer & Dual OLED Controller

Firmware driving dedicated physical transaction signer and dual SSD1306 OLED displays on Laptop B. Owns RC522 over direct SPI (SCK 18, MISO 19, MOSI 23, SS 5, RST 27); owns shared I2C bus (SDA 21, SCL 22) driving primary OLED #1 review display at address 0x3C (mandatory fail-closed) and auxiliary OLED #2 status display at address 0x3D (non-blocking status); owns direct GPIO32 (panic interrupt) and GPIO33 (sustained approve) buttons. Independently decodes EIP712 `PaymentIntent` and paginates critical fields. Panic cancels pending signing and broadcasts direct on-chain session revocation to Laptop B's Anvil node.
